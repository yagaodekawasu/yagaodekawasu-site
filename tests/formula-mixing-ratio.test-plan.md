# テスト仕様書: 調乳のお湯・湯冷まし 調合比率計算ツール

## 対象

`src/pages/tools/formula-mixing-ratio.astro`（URL: `/tools/formula-mixing-ratio`）

## 目的

調乳のお湯・湯冷ましの調合比率を計算するツールについて、簡易版・詳細版それぞれの計算結果の正しさ、入力バリデーション（エラー・警告表示）、詳細版の「室温と同じにする」チェックボックスの同期動作、入力値のlocalStorage永続化が期待どおりに動作することを確認する。

## テスト環境

- ローカル開発サーバー（`astro dev`、`http://localhost:4321`）に対してPlaywrightで実行する。
- 実装ファイル: `tests/formula-mixing-ratio.spec.ts`

## 前提条件（全ケース共通）

- 各テストケースの実行前に、ブラウザコンテキストのlocalStorageをクリアした状態でページを開く（他ケースの保存値の影響を受けないようにするため）。

## 計算式の参照値

### 簡易版（デフォルト値: 出来上がり量140ml、目標37℃、お湯80℃、湯冷まし20℃）

```
お湯の量 = 140 × (37 − 20) / (80 − 20) = 39.7ml
湯冷ましの量 = 140 − 39.7 = 100.3ml
```

### 詳細版（デフォルト値: 上記に加え、粉18g・25℃、哺乳瓶PP・50g・25℃、室温25℃、調乳時間1分）

熱量収支式（[[formula-mixing-ratio-app-design]]参照）により、お湯46.7ml・湯冷まし93.3ml。

## テストケース一覧

### 簡易版

| ID | 前提 | 手順 | 期待結果 |
|---|---|---|---|
| TC-S01 | ページを開き、簡易版タブが初期表示されている | デフォルト値のまま結果欄を確認する | お湯 39.7ml、湯冷まし 100.3ml が表示される |
| TC-S02 | TC-S01の状態 | 出来上がり量のプルダウンで200mlを選択する | 結果が即座に再計算され、お湯 56.7ml、湯冷まし 143.3ml が表示される |
| TC-S03 | TC-S01の状態 | お湯の温度を湯冷ましの温度以下（例: 20℃）に変更する | エラーメッセージ「お湯の温度は湯冷ましの温度より高くしてください。」が表示され、結果欄は「-」になる |
| TC-S04 | TC-S01の状態 | お湯の温度を70℃未満（例: 69℃）に変更する | エラーメッセージ「調乳のお湯は70℃以上にしてください。」が表示され、結果欄は「-」になる |
| TC-S05 | TC-S01の状態 | お湯の温度を70〜74℃（例: 72℃）に変更する | エラーは表示されず、結果欄には計算結果が表示される（お湯70℃以上を推奨するWHO基準に基づき、警告表示は廃止） |
| TC-S06 | TC-S01の状態 | お湯の温度を75℃以上（例: 80℃、デフォルト）にする | エラーは表示されない |
| TC-S07 | TC-S01の状態 | 出来上がり量の入力欄を確認する | `<select>`要素で、20〜300mlまで20ml刻みの選択肢が並び、デフォルトで140mlが選択されている（スマホで`<input type="number">`のスピナーが表示されない問題への対応） |

### 詳細版

| ID | 前提 | 手順 | 期待結果 |
|---|---|---|---|
| TC-D01 | ページを開く | 「詳細版」タブをクリックし、デフォルト値のまま結果欄を確認する | お湯 46.7ml、湯冷まし 93.3ml が表示される |
| TC-D02 | TC-D01の状態 | 粉ミルクの温度・哺乳瓶の温度それぞれの「室温と同じにする」チェックボックスの状態を確認する | 両方ともチェック済みで、対応する温度入力欄が無効化（disabled）されている |
| TC-D03 | TC-D01の状態（チェックボックスは両方チェック済み） | 室温を25℃から30℃に変更する | 粉ミルクの温度・哺乳瓶の温度の入力欄が両方とも自動的に30に更新され、結果が再計算される（お湯 43.8ml、湯冷まし 96.2ml） |
| TC-D04 | TC-D01の状態 | 粉ミルクの温度の「室温と同じにする」チェックを外し、値を15℃に変更する | 入力欄が編集可能になり15が入力できる。その後、室温を変更しても粉ミルクの温度は15℃のまま変化しない（哺乳瓶の温度側は引き続き室温に追従する） |
| TC-D05 | TC-D01の状態 | 哺乳瓶の材質プルダウンを「ガラス」に変更する | 比熱の違いにより結果が再計算され、デフォルト（PP）の値と異なる結果が表示される |
| TC-D06 | TC-D01の状態 | お湯の温度を70℃未満（例: 65℃）に変更する | エラーメッセージ「調乳のお湯は70℃以上にしてください。」が表示され、結果欄は「-」になる |
| TC-D07 | TC-D01の状態 | 出来上がり量の入力欄を確認する | `<select>`要素で、デフォルトで140mlが選択されている |

### 入力値の永続化（localStorage）

| ID | 前提 | 手順 | 期待結果 |
|---|---|---|---|
| TC-P01 | localStorageが空の状態でページを開く | 簡易版の出来上がり量のプルダウンで200mlを選択してからページをリロードする | リロード後も出来上がり量が200のままで、結果も200ml基準で再計算された値（56.7ml／143.3ml）が表示される |
| TC-P02 | localStorageが空の状態でページを開く | 詳細版で粉ミルクの温度の「室温と同じにする」のチェックを外してからページをリロードする | リロード後もチェックが外れた状態が保持されており、対応する入力欄は編集可能（disabledでない）になっている |

## 対象外（このスコープでは扱わない）

- 簡易版・詳細版以外の既存ページ（ブログ一覧・トップページ等）
- 視覚的なレイアウト崩れ（スクリーンショット比較によるビジュアルリグレッションテスト）
- モバイル端末でのタッチ操作固有の挙動
