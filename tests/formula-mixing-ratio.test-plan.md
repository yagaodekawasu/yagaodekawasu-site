# テスト仕様書: 調乳のお湯・湯冷まし 調合比率計算ツール

## 対象

`src/pages/tools/formula-mixing-ratio.astro`（URL: `/tools/formula-mixing-ratio`）

## 目的

調乳のお湯・湯冷ましの調合比率を計算するツールについて、簡易版・詳細版それぞれの計算結果の正しさ、入力バリデーション（エラー・警告表示）、詳細版の「室温と同じにする」チェックボックスの同期動作、入力値のlocalStorage永続化が期待どおりに動作することを確認する。

## テスト環境

- ローカル開発サーバー（`astro dev`、`http://localhost:4321`）に対してPlaywrightで実行する。
- 実装ファイル: `tests/formula-mixing-ratio.spec.ts`

## 前提条件（全ケース共通）

- 各テストケースの実行前に、ブラウザコンテキストのlocalStorageをクリアした状態でページを開く（他ケースの保存値の影響を受けないようにするため）。

## 計算式の参照値

### 簡易版（デフォルト値: 出来上がり量140ml、目標37℃、お湯80℃、湯冷まし20℃）

```
お湯の量 = 140 × (37 − 20) / (80 − 20) = 39.7ml
湯冷ましの量 = 140 − 39.7 = 100.3ml
```

### 詳細版（デフォルト値: 上記に加え、粉18g・25℃、哺乳瓶PP・50g・25℃、室温25℃、調乳時間1分）

熱量収支式（[[formula-mixing-ratio-app-design]]参照）により、お湯46.3ml・湯冷まし93.7ml。

比熱の固定値は、水4.186（物理定数）以外はいずれも根拠を調査・出典を明記したうえでの近似値（[[formula-hot-water-ratio-and-additional-cooling]]参照）: 粉ミルク1.52（MEXT脱脂粉乳データにSiebel式を適用）、ガラス0.80、ポリプロピレン(PP)1.8、PPSU 0.97、シリコーン1.4（いずれも複数資料の実測値、範囲があるものは中央値を採用）。

### メーカー規定と追加冷却（規定「1/2以上」選択時、簡易版デフォルト値）

```
規定の最低お湯量 = 140 × 1/2 = 70ml
お湯70ml・湯冷まし70ml
出来上がり時点の温度 = (70 × 80 + 70 × 20) / 140 = 50.0℃（目標37℃より13.0℃高い）
```

追加冷却時間はニュートンの冷却法則の近似式で算出する（時定数τ=7.5分、根拠は[[formula-hot-water-ratio-and-additional-cooling]]参照）。

```
t = τ × ln((出来上がり温度 − 冷却水温) / (目標温度 − 冷却水温))
```

8月（水道水温25.2℃、東京都水道局データ）を基準にすると、流水で約5.6分・氷水（0℃）で約2.3分。

### 計算の根拠セクション（簡易版・詳細版）

計算結果・追加冷却案内の下に、計算式や固定値の根拠（[[formula-hot-water-ratio-and-additional-cooling]]参照）をユーザー向けに示す折りたたみセクションを設置する。初期状態は閉じている。

簡易版は加重平均の式（お湯の量 = 出来上がり量 ×（目標温度−湯冷ましの温度）÷（お湯の温度−湯冷ましの温度））を示すが、詳細版は実際の計算ロジックが異なる（粉ミルク・哺乳瓶の熱容量、調乳中の放熱を考慮した熱量収支式）ため、内容も詳細版専用のものにする。共通なのは「追加で冷やす時間の目安」「流水（水道水）の温度」の2セクションのみ。

### 入力値の永続化（localStorage）

| ID | 前提 | 手順 | 期待結果 |
|---|---|---|---|
| TC-P01 | localStorageが空の状態でページを開く | 簡易版の出来上がり量のプルダウンで200mlを選択してからページをリロードする | リロード後も出来上がり量が200のままで、結果も200ml基準で再計算された値（56.7ml／143.3ml）が表示される |

## 対象外（このスコープでは扱わない）

- 簡易版・詳細版以外の既存ページ（ブログ一覧・トップページ等）
- 視覚的なレイアウト崩れ（スクリーンショット比較によるビジュアルリグレッションテスト）
- モバイル端末でのタッチ操作固有の挙動
